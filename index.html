Conoce las opciones

Tipos de Apertura

Cada espacio necesita un tipo de apertura diferente. Conoce cómo funciona cada sistema y elige el ideal para tu proyecto.

Proyectante

Se abre hacia afuera desde el borde inferior. Permite ventilación incluso con lluvia, perfecta para baños y cocinas.

Cotizar →

Oscilobatiente

Combina dos movimientos: abatible lateral completo o basculante superior para ventilación parcial. El sistema más versátil del mercado.

Cotizar →

Corrediza

Se desliza horizontalmente sobre rieles. No ocupa espacio al abrir, ideal para balcones, terrazas y espacios reducidos.

Cotizar →

Corredera Elevable

El panel se eleva ligeramente y se desliza con mínimo esfuerzo. Diseñada para grandes ventanales y puertas de terraza de alto peso.

Cotizar →

Practicable Interior

La hoja se abre completamente hacia el interior del espacio. Ideal para limpieza fácil desde adentro y máximo sellado hermético.

Cotizar →

Practicable Exterior

La hoja se abre hacia afuera, liberando espacio interior. Perfecta para habitaciones pequeñas donde cada centímetro cuenta.

Cotizar →

Abatible

La hoja abre sobre bisagras inferiores con un ángulo de 20° hacia el interior, permitiendo ventilación sin sacrificar espacio.

Cotizar →

Plegable

Puerta tipo acordeón para grandes formatos que maximiza el espacio de salida.
